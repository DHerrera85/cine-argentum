# Cine Argentum | Argentina Content

Catálogo interactivo de cine y series argentinas. Reúne fichas de producciones, elencos, imágenes, datos de audiencia y opciones para explorar contenido por género, canal, plataforma y década.

🔗 **[Visitar el sitio](https://dherrera85.github.io/cine-argentum/)**

## Qué ofrece

- Fichas de películas y series con sinopsis, elenco e imágenes.
- Catálogos de televisión organizados por canal y período.
- Filtros por año, género y categoría, con ordenamiento por rating.
- Rankings de producciones y películas según audiencia.
- Secciones de streaming, juveniles y producciones relacionadas.
- Diseño adaptable a computadoras y dispositivos móviles.

## Tecnologías

HTML, CSS y JavaScript. El contenido del catálogo se administra principalmente desde `data.json` y se publica mediante GitHub Pages.

## Probar en local

Como el sitio carga archivos JSON mediante `fetch`, abrí una terminal en la carpeta del proyecto y ejecutá:

```powershell
python -m http.server 5500
```

Luego visitá [http://localhost:5500](http://localhost:5500).
